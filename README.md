#Nombre del proyecto
    ##Urban Routes, pruebas automatizadas

#Descripción del proyecto
    ## Pruebas automatizadas para la aplicación Urban Routes que verifica el flujo completo
    ##  de configurar la dirección, seleccionar la tarifa comfort, rellenar el numero de teléfono,
    ## agregar tarjeta de credito como metodo de pago, un mensaje para el conductor,hacer algunas
    ## solicitudes mas y comprobar que aparezca el taxi y los mensajes del conductor

#Tecnologías y técnicas utilizadas
     ##Python
     ##Selenium WebDriver
     ##Pytest
     ##Page Object Model (POM)
     ##Pycharm
